## 出门前与连接恢复

**当前部署需要携带这台电脑和支持数据传输的 USB 线。** DeepSeek 网关在电脑本机运行，经 USB 转发给手机。电脑须能访问 DeepSeek，保持开机、不休眠、数据线连接。手机离线仍能看任务、材料、提交历史和安排，并核对保存已经暂存的草案；离线不能分析新通知。没有部署全天在线远程网关。

本机工作区提供 `启动课事清演示.cmd`（便利文件，不进仓库），双击后保持窗口开启。其他机器可在仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-demo-gateway.ps1 -GatewayDirectory 'D:\你的本机网关目录'
```

该目录需已有 `main.py`、`notice_extraction.py`、`requirements.txt`、私有 `.env` 和在本机重建的 `.venv`，不要搬运别人的虚拟环境或上传 `.env`。启动器只监听127.0.0.1:8000，建立USB8000转发；端口或映射占用即停止，不替换其他会话。

窗口显示 Gateway ready 后，手机“设置”填 `http://127.0.0.1:8000` 和团队项目凭证 `GATEWAY_TOKEN`，点“应用设置并返回”。服务商 API Key 留在电脑，不能填手机或展示给老师。配置有效不等于网络已连接，实际以发送结果为准。

凭证仅存在本次运行内存，**完全退出/重启App后需重新应用凭证**，任务不会丢失。未配置时首页固定显示引导。USB重连后连不上：Ctrl+C关闭自己的启动器，重新启动并核对手机设置。提示占用时先关闭自己上次的网关窗口，不随意终止别人进程/删除映射。启动器Ctrl+C仅停止自己启动的进程和移除自己的映射，已实际检查。

## 给老师的顺序（约四分钟）

1. 点桌面“课事清”，展示“任务助手”及“我的任务 / 安排 / 设置”。配置模型后点“新对话 → 确认新建”，历史仍保留。本次文字流程无需录音、播报。
2. 粘贴整段合成原通知，点发送。说明模型自己提取任务、截止、要求，无需用户逐字段填表：

   > 合成演示通知：人机交互课程2026年12月25日前交可用性报告，需要PDF报告和原型截图，提交到课程平台。没有给具体截止时刻，也没说需要多少工时。

3. 核对方案的标题、课程、2026-12-25、两项材料及原文；时刻/工时应保持未知，若模型追问按通知实际补充。先展示“尚未保存”，再点“确认并保存”，看本机回执。这不是学校平台提交。
4. 进“我的任务”，搜索“可用性报告”，展示日期、材料和来源。本机已有一条同名合成演示任务；若再次演示出现候选，核对后选择，不把旧任务冒充新建结果。材料改变仍需预览及确认。
5. 返回首页点“安排”，展示可用时间和已有两条已完成工作块。新候选需先明确工时、可排程的精确截止和可用时间，再预览/确认；不能给只有日期的通知硬排截止时刻。模型目前可读取本应用安排，尚无自然语言生成/保存工作块工具。
6. 回“我的任务”打开已有“合成提醒与材料验收任务”，展示材料、用户标记已提交的历史及提醒入口。只有日期的任务不能生成精确提醒；本次不触发近期提醒、录音或播报。远期登记/改期/取消有独立证据，到点送达和提示音仍未验证。
7. 可选：完全关闭并重启课事清，展示任务/材料/历史离线仍在。继续分析新通知前重新应用项目凭证。
