## 2. 接口草案（对齐总纲9.1）

**GET /health**

```json
{ "status": "ok", "model": "deepseek-flash" }
```

**POST /api/model/turn** — 请求

```json
{ "message": "用户输入", "context": { "taskId": null }, "tools": [ { "type": "function", "function": { "name": "get_tasks", "parameters": { "type": "object", "properties": { "course": { "type": "string" } } } } } ], "results": [] }
```

返回三类：

```json
{ "type": "answer", "text": "..." }
{ "type": "tool_calls", "calls": [{ "action": "get_tasks", "params": { "course": "数据库" } }] }
{ "type": "clarification", "question": "..." }
```

错误统一：`{ "type": "error", "errorCode", "message", "elapsedMs" }`（`requestId` 待补，总纲9.1 要求）；日志只记 requestId、耗时、错误与用量，不写密钥/通知原文/音频。

## 3. 真实调用记录

| 项 | 值 |
|---|---|
| 模型 | deepseek-flash（上游端点 `https://api.deepseek.com/chat/completions`） |
| JSON 结构化输出 | 通过：HTTP 200，返回合法 JSON，title/course/deadline/submissionChannel/materials 均正确 |
| function calling | 通过：HTTP 200，返回 tool_calls `get_tasks`，参数 `{"course":"数据库"}` |
| 延迟 | JSON 测试 2.42s；工具调用 0.96s |
| 网关端到端 | 通过（thinking disabled）：`/api/model/turn` → deepseek-flash → answer，1.93s，14 tokens（无 reasoning） |
| 用量 | JSON 测试 237 tokens（reasoning 71）；工具调用 347 tokens（reasoning 17） |
| 费用 | 验证测试合计 ≈ 0.0023 元（闲时·缓存未命中：输入 1.00、输出 4.00 元/百万 tokens） |

说明（thinking 实测 2026-10-27）：`deepseek-flash` 不设 `thinking` 时默认输出 `reasoning_content` 并计推理 token；设 `thinking: {"type": "disabled"}` 可关闭思考——实测无 `reasoning_content`、无 `reasoning_tokens`，延迟 0.76s（对照 2.28s）、14 tokens（对照 169）。function calling 在 `disabled` 下亦正常（实测返回 `tool_calls`、无 reasoning_token）。本项目 DDL Agent 场景默认采用 `disabled`，网关 `server/main.py` 已内置。

计价（官方，元/百万 tokens，2026-10-27）：闲时·缓存未命中 输入 1.00、输出 4.00；缓存命中 输入 0.02；高峰（工作日 9:00–12:00、14:00–18:00）为 2 倍。本次测试均为闲时、缓存未命中。
