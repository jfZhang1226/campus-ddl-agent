## 2. 接口草案（对齐总纲9.1）

**GET /health**

```json
{ "status": "ok", "model": "deepseek-flash" }
```

**POST /api/model/turn** — 请求

```json
{ "message": "用户输入", "context": { "taskId": null }, "tools": [ { "type": "function", "function": { "name": "get_tasks", "parameters": { "type": "object", "properties": { "course": { "type": "string" } } } } } ], "results": [] }
```

返回三类：

```json
{ "type": "answer", "text": "..." }
{ "type": "tool_calls", "calls": [{ "action": "get_tasks", "params": { "course": "数据库" } }] }
{ "type": "clarification", "question": "..." }
```

错误统一：`{ "type": "error", "errorCode", "message", "elapsedMs" }`（`requestId` 待补，总纲9.1 要求）；日志只记 requestId、耗时、错误与用量，不写密钥/通知原文/音频。
