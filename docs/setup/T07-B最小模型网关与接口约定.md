## 2. 接口约定（对齐总纲9.1、9.2）

**认证**：`POST /api/model/turn` 需要请求头 `Authorization: Bearer <GATEWAY_TOKEN>`。`GATEWAY_TOKEN` 是项目网关凭证（`.env` 配置，与服务商 `DEEPSEEK_API_KEY` 无关），客户端只有本项目凭证、没有服务商权限。`GET /health` 无需认证。

**限流**：按网关凭证分桶的内存滑动窗口，默认每凭证每分钟 30 次（`RATE_LIMIT_PER_MINUTE` 可调），单进程演示部署适用。

**GET /health**

```json
{ "status": "ok", "model": "deepseek-flash" }
```

**POST /api/model/turn** — 请求

```json
{
  "message": "用户输入",
  "context": { "taskId": "T1", "timezone": "Asia/Shanghai" },
  "tools": [ { "type": "function", "function": { "name": "get_tasks", "parameters": { "type": "object", "properties": { "course": { "type": "string" } } } } } ],
  "results": [
    { "id": "call_1", "action": "get_tasks", "params": { "course": "数据库" },
      "success": false, "data": null, "errorCode": "STORAGE_FAILED", "message": "本地存储失败" }
  ]
}
```

- `context`：任务/时区等必要上下文，网关作为 system 消息传给模型。
- `results`：上一轮模型发起的工具调用及其真实执行结果；`id/action/params` 用于映射上游 `tool_call_id`（`params` 可省略，默认 `{}`），`success/data/errorCode/message` 转为 tool 消息回传，模型据此读到真实查询结果或失败信息。网关不实现 Repository 或 T16 提交协议。
- 未声明为无状态单轮，因此这些字段不会被静默忽略：`context`、`results` 均转换为上游消息。

返回三类（均含 `requestId`）：

```json
{ "type": "answer", "text": "...", "requestId": "..." }
{ "type": "tool_calls", "calls": [{ "id": "call_1", "action": "get_tasks", "params": { "course": "数据库" } }], "requestId": "..." }
{ "type": "clarification", "question": "...", "requestId": "..." }
```

错误统一为 `{ "type": "error", "errorCode", "message", "requestId", "elapsedMs" }`，HTTP 状态码配合：

| errorCode | HTTP | 场景 |
|---|---|---|
| `UNAUTHORIZED` | 401 | 缺少或无效的网关访问凭证 |
| `RATE_LIMITED` | 429 | 超过限流阈值 |
| `INVALID_REQUEST` | 400 | 请求体/`results` 结构不合法 |
| `CONFIG_ERROR` | 500 | 服务端未配置网关凭证或服务商密钥 |
| `MODEL_ERROR` | 502 | 上游请求异常、非 200、响应非 JSON/缺 choices/message、工具参数解析失败或非对象 |

日志只记 requestId、耗时、错误与用量，不写密钥/通知原文/音频。

计价（官方，元/百万 tokens，2026-10-27）：闲时·缓存未命中 输入 1.00、输出 4.00；缓存命中 输入 0.02；高峰（工作日 9:00–12:00、14:00–18:00）为 2 倍。本次测试均为闲时、缓存未命中。
