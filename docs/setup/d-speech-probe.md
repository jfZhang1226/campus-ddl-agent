## 2. 最小验证顺序

1. 先用团队共享工程完成自己的构建/安装/启动复核，记录提交和工具版本。
2. 使用合成口述：“请记录2026年11月6日18点交数据库实验报告”，验证麦克风权限与录音；保存实际格式/时长，不填预计值。
3. 独立验证 ASR，显示实际转写并允许编辑。记录失败原文与错误码，不将期望文本当实测返回。
4. 独立验证 TTS：“已整理为草案，请先核对”，再点击停止，确认真实音频中断。
5. 测权限拒绝、取消、空识别、服务失败、离页与后台，以及旧回调不覆盖新输入。
6. 原生路径确受限制时记录限制，再与 A/B 对齐录音/播放及云服务备选。只实现一条已选择路径，不同时维护两套完整语音业务。
