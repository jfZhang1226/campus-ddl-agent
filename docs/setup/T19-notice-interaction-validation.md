## D 本轮实现

1. NoticeImportController返回上一轮原始draft与累计显式answers；同字段取当前最后值，清空保留null/空串。保留用户明确修改的材料、优先级和工时，避免端点缺少相应answer字段而覆盖编辑；新原文和明确取消清理旧覆盖。原文不拼接成“原文+已填写答案”。
2. NoticeVoiceController复用T13与现有SpeechSession：转写只填原文，人工发送才调用T12；录音/提取/播报/确认互斥。每次人工编辑记录代次，改回原文和超过4000字符的人工文本均不被迟到ASR覆盖。
3. 取消和后台作废录音/网络回调，手动播报明确“待确认草案，尚未保存”，有就近停止，最多500个UTF-16单元且不截断高代理项。
4. 受控导出复用T13页面和T15平台装配，来源信息折叠、新包com.campusddl.noticeprobe，不覆盖业务/T15包。保存接口未齐，使用只读gate并明确禁用保存。
