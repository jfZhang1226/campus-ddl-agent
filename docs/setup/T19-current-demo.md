## 三分钟主流程

1. 在独立联调包设置团队网关根地址/项目访问凭证，进入“任务对话联调”。服务商API Key仅在本机网关，屏幕不展示凭证。
2. 手动录音或粘贴合成通知：“软件工程报告需要PDF报告和源代码，交到课程平台，截止时间还没公布。”语音完成先核对文字，再点发送。
3. 检查模型生成的任务/课程/材料，日期未知就保留未知。继续发“截止日期是2026年12月10日，没有具体时刻，其他要求不变。”核对date_only与原文/补充分别保留。
4. 可手动播报待确认方案并停止；开头说明尚未保存。检查来源后点击屏幕确认，展示实际本机回执与当前材料。
5. 发合成补充“刚才的软件工程报告截止日期改为2026年12月12日，没有具体时刻，其他要求保持不变。”展示先查真实任务、旧新日期与来源，确认后同一任务改期、两材料保持。
6. 停止网关并重启本独立包，地址/凭证空时仍能读同一任务、日期、材料与来源。不要卸载或清数据。

步骤2—4的ASR/模型/听播报/确认冷读在aef8469完成；缺日期加一句补充在ff94007共享文字入口完成；步骤5与新停顿设置在6824a74完成。不能把这些不同来源拼成同一个全新包已完整彩排；正式演示前应绑定最终源码重做一遍。

## 可说明但不能夸大的部分

- 模型负责从消息分析字段，用户不必提前填好全部信息；日期数字/汉字形式本身无需互转，最终以草案核对及日期校验为准。
- 语音识别仍会有同音字和英文缩写错误。2秒左右自然停顿已试过连续转写，不能宣称零误识别、无限录音或任意打断都恢复。
- 系统到期提醒、安排表、自动排程、通用材料状态操作尚未接入此页；不能演示假成功。任务存本机，不代表学校平台收到作业。
- 不自动扫描微信/QQ群、不代登录/发消息或提交作业。当前可直接放入原通知或手动语音输入，跨软件分享能力另按已有入口实际验证。
- 当前只有合成样例有限验证，未组织同学试用、留出集统计或跨端完整验收。按一次成功文字流程观察6620 tokens，不作为平均成本/准确率。
