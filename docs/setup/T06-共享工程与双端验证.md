## 1. 实际创建方式

在 `feat/a-t06-arkui-x` 任务分支，使用已安装 SDK 26.0.0.28 Beta2 随附 ACE 创建 `client/`：

```text
ace create client
project name: CampusDdlAgent
bundleName: com.campusddl.agent
runtimeOS: HarmonyOS
Compile SDK: 26.0.0
platform: Default(Android, iOS)
```

使用的是实际 ArkUI-X 模板；`entry/src/main/ets/pages/Index.ets` 为两端共用的 `Hello World` 页面，`.arkui-x/android/` 包含承载相同页面的 Java 宿主、Manifest 和 Gradle wrapper。iOS 目录来自默认模板，未在本轮验证。

没有为 Android 再写一套业务或 UI，也没有接入模型、任务 CRUD、语音或本地历史。后续 C、D 从 `entry/src/main/ets/` 接入数据与平台能力；不能把本次模板编译当作 T08/T09/T10 功能完成。
