## 大字简洁模式

进入“设置”，向下找到独立的“大字简洁模式”开关。连接设置仍排在前面。开启后正文和操作字体同步放大，辅助说明收起；通知原文、提交记录和连接设置仍可按需打开。任务、截止、材料和确认保存保留，模式会自动记住，重启无需重选。关闭开关可恢复普通模式。本轮验证后手机保留普通模式，供你自行选择。

## 更清楚的切换与互动

底部固定顺序为助手、任务、安排、设置，向右侧栏目切换时从右进入，向左则从左进入。顶部绿色方块助手已明显放大，空闲时点它可挥手，处理状态继续对应实际业务。

输入区可展开核对长通知；大字模式默认使用更高输入框。输入时在对话区或顶部向下滑即可收起键盘，文字仍保留，输入框内的长文字滚动不受影响。“设置”里的保存按钮突出显示，清除仍需确认，连接凭证保持安全存储。[本轮设计](../design/D-large-simple-mode.md) · [实际检查](evidence/ui-mode-20261125.json)。

## 自动记住连接

首次在“设置”填写服务地址和团队项目凭证，点“保存连接设置”。当前鸿蒙版会在手机安全存储中保存，完全退出再打开也会自动恢复，无需每次重填；凭证框只显示已设置，不回显原值。换凭证时输入新值，留空保留现有凭证。

“清除连接信息”确认后仅删除连接，任务、草案和聊天保留。手机锁定或安全读取失败时，解锁后可点“重新读取连接”。其他尚未接入安全存储的平台只支持本次连接，不冒充已经记住。

这不会让手机自动启动电脑网关；电脑服务与USB转发仍需保持。0.9.0历史验证：源码3b08d0e，180源码/89指纹，127项相关主机检查、真实换进程恢复/清除/重配和业务快照不变检查通过；当时没有发新模型或语音测试。[安全保存说明](../decisions/D-device-gateway-secret.md) · [历史证据](evidence/secure-gateway-20261125.json)。

## 小助手

采用第四版绿色方块形象。待机时会眨眼，空闲时点它可以挥手；分析通知时托腮思考，确认保存时拿本子记笔记。动作跟实际处理状态对应，草案未确认不代表已保存。已有对话时也能点顶部小助手。

需要一次看全四组动作，可进“设置 → 调试工具 → 小助手动作预览”；此入口不会发送通知、保存任务或播放声音。[查看动作预览与说明](../design/D-assistant-mascot.md)。

## 整理通知

在“助手”粘贴通知，或点“语音输入”展开录音操作。转写只填输入框，核对文字后自行发送。模型整理出草案后，先检查任务、材料及原文，再点“确认并保存”。未确认的方案不是正式任务。

录音、发送和播报仍分别由你触发。只有需要排错时才显示恢复操作，旧探测页面放在“设置 → 调试工具”。

## 直接补充截止时间

- 草案：点截止旁的“补充”或“编辑”，选择日期和可选时刻，点“应用到草案”；回到草案核对后再确认保存。
- 已保存任务：“任务 → 查看详情 → 截止时间右侧编辑”，应用后先展示修改方案，核对旧时间和新时间，再点“确认保存修改”。取消不会改变正式记录。
- 不知道时刻可选“时刻暂不确定”，日期也未知可选“日期也待定”。选择器展示的默认值不会直接成为截止，必须明确选择并应用。
- 这一步在本机完成，支持离线，不需要重新请求模型。人工补充单独保留来源，原通知不会被改写。改期后请核对既有提醒及工作安排。

## 材料、进度和提醒

任务详情可勾选材料，点“核对准备情况”后再确认。新增材料、剩余工时和任务进度位于“管理材料与任务进度”；用户提交声明历史单独保留。应用不会代你向学校平台提交。

点“截止前提醒”展开设置。精确提醒需要明确截止时刻和系统权限；只知日期时先补时刻，或继续保留未知。本轮没有触发到点提醒或提示音，不把登记成功当作实际送达。

## 安排自己的时间

在“安排”点“添加可用时间”，选择日期、开始和结束时刻，添加后先核对保存。然后点“生成七日安排”，核对候选再确认。任务缺工时或确切截止时会显示缺项，需要到详情补充。完成工作块时明确填写剩余工时，不自动标记任务已提交。

完整时间文本与安排范围保留在展开设置中；普通添加时段无需手写长时间串。已有锁定和完成历史保留。

## 连接助手

现有DeepSeek网关仍在电脑运行，通过USB转发给手机。当前部署需电脑开机联网并保持数据线连接。运行 `scripts/start-demo-gateway.ps1`，手机“设置”填写服务地址 `http://127.0.0.1:8000` 和项目访问凭证；服务商API Key留在电脑。

当前鸿蒙版的连接信息会安全保存在手机，App重启自动恢复；已有任务、草案和安排仍可离线查看及核对保存。USB重连后如果失效，恢复电脑服务与转发即可；更详细的启动步骤见[连接恢复说明](DEMO_APP_GUIDE.md#出门前与连接恢复)。
