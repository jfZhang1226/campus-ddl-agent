# D / T15：先用独立鸿蒙联调包验证共享语音对话协调

日期：2026-11-04。状态：本地有限实现，待 A/B 评审；不等同正式主页面已接入。

T09 阶段性代码已有 A/B 批准，A 另提供实际安装包的语音补测报告。用户要求开始 T15，并确认手机已连接、稍后方便录音和听播报。本轮仍不改团队业务应用的安装、数据和共享平台检查。

## 装配方式

- 新增共享、无平台 Kit 依赖的 `VoiceChatController`，组合既有 `ChatController` 与结构化 `SpeechSession` 端口。ASR 只填草稿，人工点击才发送；请求继续走既有 `ArkGatewayTransport` / `/api/model/turn`，不增加第二个网关或云语音端点。
- Harmony-only 页面和所有者放在 `probes/harmony-voicechat/`，通过受控导出复用 T09 原生适配及共享代码。平台差异开关仍只存在于生成的独立工程；生产 Index、EntryAbility、ArkUI-X 配置、网关均未改动。
- 联调包沿用已授权签名的独立 `com.campusddl.speechprobe`，版本改为 0.2.0 / 200，入口“课事清语音联调”；保留 T09 探测页。更新只针对该包，不覆盖 `com.campusddl.agent` / label。权限为麦克风与互联网，无录音文件保存或音频上传。
- 联调 owner 独占一个 ChatController 观察者。正式接入时应由 A 复用 `chatOwner.get()` 并统一页面订阅，不能把两个订阅者同时挂在现有单 listener 接口；还需核对非鸿蒙能力反馈和平台工厂。当前未声明 Android/iOS 语音装配完成。

## 约束与后续

语音、模型、任务保存和播报分别反馈。播报须手动点击，开头说明本页没有保存任务；长回复仅播报开头、全文留在文字中。页面离开/后台作废语音代次，取消模型等待，不自动续播。此联调不实现 T19、T13/T16/T17、持久会话或系统提醒。

真实模型需要用户提供可用团队网关，在手机自行填写项目凭证，不读取其他应用配置或索取服务商 Key。本机合成服务只是验证网络和交互的固定回复，页面明确标注，不代替真实模型链路验收。签名配置和 HAP 只留本机。
