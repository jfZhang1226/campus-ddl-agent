# 大字简洁模式与切栏体验

2026-11-25。面向普通用户的显示选项，保留原暖灰、墨绿与第四版 D 方块助手。

## 底部四栏

固定顺序为助手、任务、安排、设置。目标位于当前栏右侧时从右侧进入，目标在左侧时从左侧进入；不再由路由 push/pop 或访问历史决定方向。四页同时配置进入和退出转场，时长 240ms。

切换前仍执行原有忙碌、时间编辑、材料勾选、设置输入和安排草案保护。实际页面显示后释放导航锁；旧路由完成回调不能解除新一次导航的锁。该机制覆盖真机在反复返回助手后再次进入任务失效的问题，未修改业务控制器。

## 方块助手

顶部尺寸由 48 调整为普通模式 104、大字模式 96。去掉首页和处理状态区重复的第二个助手，集中为一个可点击的互动形象。普通模式保留“点我打个招呼”，空闲点击沿用挥手；思考、记笔记、眨眼及离页停止仍使用原状态映射和 16 帧素材，不让未确认方案表现为保存成功。

## 大字简洁模式

连接信息与连接操作优先，大字简洁模式单独放在设置下方的显示区域，可随时开启或关闭。四个主页面、对话、底栏、截止时间与可用时间编辑同步响应：

- 可见正文和提示不小于 18；常用正文约 20～22，标题更大。操作按钮最小高度 56，长标签允许换行，筛选和部分操作行可折行。
- 收起装饰文案、重复引导和助手角色小标签。任务来源、提交历史、连接维护按需展开；核心任务、截止、课程、材料、确认和错误仍可读取。
- 输入保持原控制器，简洁模式使用更高的输入区，不清空、提交或改写内容。
- 连接未配置、读取失败、存在未应用连接输入或清除确认时，连接表单仍可见。安全保存、重读和确认清除保持原逻辑；原口令继续不回显。
- 保留普通模式，可随时关闭；不会自动改变手机系统字体或无障碍设置。

## 下滑收起键盘

输入框获得焦点后，在对话区或顶部向下滑动即可收起键盘，使用原生焦点控制，不清空输入、不发送或保存消息。手势与对话滚动并行，输入框本身不绑定该手势，保留长输入的内部滚动。向上滚动、点击或短距离移动不触发收起。

## 只保存显示偏好

`UiPreferencesOwner` 通过既有文件端口和快照原语在独立 `campus-ui/display-settings.json` 保存布尔选项及结构/修订版本，不写入业务快照、会话或网关资产，不保存任何凭证。原子替换成功才应用模式；失败保留旧外观并提示，坏记录和未知版本不静默覆盖。并发写入拒绝旧修订，页面开关失败后回到实际生效状态。

对应 `scripts/test-ui-experience.cjs` 的 14 项检查包括所有切栏方向、并发与迟到回调、模式冷恢复、写入失败、坏记录、版本冲突、连接优先顺序和键盘手势不改动输入。源码检查与实际设备检查分开记录，设备结果见本轮状态与证据，不把主机测试等同视觉验收。

原生转场依据：[华为页面转场说明](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/arkts-page-transition-animation/)，并已使用本机 API26 SDK 编译核对。
