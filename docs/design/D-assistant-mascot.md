# 绿色方块小助手

2026-11-25，采用本人选定的第四版 D：深绿方块身体、浅绿像素脸、黄色方形点缀。形象由内置绘图工具生成，原始透明 PNG 直接作为资源，不在运行时生成图片。

## 四组动作

每组 4 个关键帧，以 2×2 图集保存，按左上、右上、左下、右下读取，共 16 帧。`AssistantMascot` 仅裁出当前格，不依赖 GIF 解码或额外动画库。

| 动作 | 实际触发 | 节奏 |
| --- | --- | --- |
| 眨眼 | 可见页面中的空闲状态 | 睁眼停留 2.8 秒，再半闭、闭眼、睁眼 |
| 挥手 | 空闲时点击首页或顶部的小助手 | 1.8 秒后回到待机；不会打断分析/保存 |
| 思考 | 初始化、分析、整理草案、恢复等实际处理中状态 | 托腮、轻轻侧头；尚未确认时不显示保存成功 |
| 记笔记 | 客户端进入实际 saving 阶段 | 拿本子写字；仅成功获得新保存回执后短暂保留“已保存到本机” |

失败返回安静状态，历史保存回执不会触发一次新的成功动画。顶部小助手在已有对话时仍可互动。动作不调用模型、不增加模型 token，不启动录音、播报、提醒或业务写入。页面隐藏/销毁时取消动画定时器，旧回调不能重新启动。
