# 暖灰墨绿界面

2026-11-25，按用户对对话白蓝底、长期配置提示和调试页残留蓝色的反馈调整。

## 视觉与交互

- 暖灰页面、浅鼠尾草绿用户气泡；助手回复直接排在页面上，不再套白色大底卡。复用 `MessageBubble.ets`，保持用户/助手、处理中/失败状态和文本复制。
- 统一正文行距、留白、卡片圆角与细边框。输入框和发送操作合为一体面板，使用更深的灰绿底和独立边框，编辑时显示细墨绿描边，与输出卡片区分；底部四入口为轻量圆角栏。
- 任务、安排、连接设置、日期与时段编辑中的按钮都有明确样式，避免系统默认亮蓝按钮；主要确认操作为墨绿。调试工具菜单也统一全部按钮与背景，并支持滚动。
- `AppTheme.ets` 集中颜色；图标线条、启动背景和原生系统栏同步。系统栏配色失败不阻塞启动。选定三种背景上的辅助文字对比度计算均不低于 4.69；没有据此宣称完整可访问性验收。
- 设置中的“调试工具 → 对话样式预览”使用真实消息组件与合成内容，不调用模型或保存任务，供看长短气泡及排版。

## 配置提示

配置成功只清除 `CONFIG_URL/CONFIG_TOKEN/CONFIG_TIMEOUT` 及其旧提示。不会清除鉴权、网络或业务保存错误；无效的自动配置也不覆盖已存在的非配置错误。主页不重复展示字段校验提示或无关“重新加载”按钮，未配置时保留单一连接入口；字段错误仍在连接设置中显示。

原先一直显示的“请输入网关地址”来自配置成功后旧错误未清理。本轮有两项回归检查：三个本地配置错误纠正后消失、无额外模型/存储写入；已有真实请求失败不会被配置动作抹去或重发。
